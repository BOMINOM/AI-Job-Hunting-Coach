# AI Job Hunting Coach · AI 求职教练

> 一款面向求职者的个人求职管理与面试训练工具。覆盖「投递追踪 → 面试准备 → 真实复盘 → 数据洞察」全流程，帮你把碎片化的求职过程变成可管理、可复盘、可优化的个人资产。  
> 纯前端单文件应用，数据默认存在你本机浏览器，支持通过 GitHub Gist 实现多端同步。

在线预览：<https://bominom.github.io/AI-Job-Hunting-Coach/>

## ✨ 功能模块

### 🏠 Home 首页

每日 AI 智能推送中心，统一汇总求职相关待办事项、时间节点提醒、岗位风险预警，打开页面即可直观查看当日需要跟进的求职任务，快速掌握整体求职进度；同时整合关键数据分析，一屏掌握求职核心指标。

### 📂 Applications 岗位投递看板

1. 可视化求职流程看板，划分五大求职阶段：已投递 / 笔试·测评 / 面试中 / Offer / 拒绝·放弃。
2. 支持卡片跨阶段自由拖拽调整求职进度；支持自定义新增求职阶段与反馈类型；全程记录能力标签，便于后期针对性提升。
3. 系统自动计算岗位与简历的匹配度（简历内容在「设置」中维护）；
4. 长期无反馈的职位可一键归入右下角「无反馈」集中管理；

### 🎯 Interview Hub 面试训练中心

核心面试辅助功能：

1. Mock 模拟面试：基于岗位真题、JD语义匹配自动生成面试考题，全真模拟面试问答场景，提前演练答题思路；
2. 个人素材沉淀：持续沉淀个人经历库与行为面试题库，将面试素材与真题资产化，越用越厚。
3. 面试锦囊 Cheat Sheet：抓取岗位JD关键词优先展示，以气泡墙形式陈列面试核心要点，单页最多容纳20个内容气泡，面试前快速梳理作答素材；「关键数据」可一键套用预设关键词，并支持把预设一键同步到其他岗位。

### 📝 Interview Review 面试复盘

面试后结构化沉淀工具，完整记录整场面试过程，支持多种录入方式，依托AI生成标准化复盘报告，梳理面试整体表现、答题亮点、薄弱项与优化建议，自动收录至个人真题库，持续沉淀面试经验。

### 📈 Insights 求职数据洞察看板

量化分析全部投递数据，多维度可视化图表展示求职效能：投递转化漏斗、招聘渠道平台投递效果对比、各档位薪资分布对比，直观定位求职短板，辅助优化投递策略。

### ⚙️ Settings 设置中心

应用全局配置入口，包含以下核心配置项：

1. 简历管理：支持上传多份简历，集中维护不同版本求职素材，可设置默认版本用于简历匹配；
2. AI 能力配置：填写大模型厂商、API Key、选择模型，解锁复盘、模拟面试、关键词解析全部AI功能；
3. 多端同步配置：填入具备Gist读写权限的GitHub Token，将本地求职数据备份至私有Gist，实现电脑、手机跨设备数据同步，同时包含数据管理、本地缓存相关基础设置；
4. 能力标签词库：支持手动增删个人能力标签（维护能力标签词库）；
5. 支持全量数据一键导出。

## ⚠️ 通用注意事项（务必先看）

1. **数据按网址隔离**：应用数据存浏览器 localStorage，按你打开的链接/域名隔离。换链接、清浏览器缓存都会让数据「看起来消失」，多端同步是解决跨设备的方法。
2. **本地优先**：未配置同步时，数据只在本机本浏览器；重要数据请善用「立即上传」与多端同步。
3. **AI 功能需自备 Key**：所有 AI 能力（复盘、匹配、Mock、锦囊生成）都依赖你在「设置」里配置的厂商 API Key，应用本身不提供 Key。
4. **纯前端、无服务器**：不收集你的任何求职信息，隐私由你自己掌控。

> 使用建议：先在「设置」完成 AI 配置与多端同步，再开始录入岗位；手机端想看电脑端最新数据，记得先在电脑端点「立即上传」。

## 技术形态

纯前端单文件原型：`index.html` 即真相源。无后端、无构建步骤、无外部 CDN，浏览器直接打开即用。
