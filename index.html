🤖 AI 面试官（可选 · 联网）

模型名规则：火山引擎方舟需填你创建的推理接入点 ID（如 ep-abc123）；其他厂商通常直接填模型名。密钥仅保存在本机浏览器（localStorage），不会上传到任何服务器；调用失败时自动回退脚本逻辑。

☁️ 多端同步（手机/电脑，GitHub Gist）

基于 GitHub Gist + 个人访问令牌（Token）。数据存放在一个私有 Gist 文件 ajhc_data_backup.json；多端使用同一个 Token 即自动同步，本机数据改动会每 1 小时 自动上传一次；不到 1 小时急着同步，可点下方「立即上传」手动触发合并。Token 仅存你本机浏览器，不会进入备份文件。
📖 查看设置方法（点击展开）

第一步：生成 GitHub Token
打开 https://github.com/settings/tokens?type=beta → 点「Generate new token」→ 勾选 gist 权限（读写）→ 生成并复制令牌（只显示一次）。

第二步：在应用里连接
Settings → ☁️ 多端同步 → 粘贴 Token → 点「💾 连接并同步」。
首次会自动新建一个私有 Gist 并上传本机数据；换设备时粘贴同一个 Token → 点「连接并同步」即可拉取。

关于数据隔离
每个 Token 对应一份私有 Gist，不同人/不同 Token 之间数据完全隔离、互不互通。

📤 数据导出

各数据独立下载，按需自由选择；支持 CSV 与 Excel（.xlsx）。简历数据不导出。
